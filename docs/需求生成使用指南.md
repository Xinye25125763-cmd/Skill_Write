# 需求生成使用指南

本指南面向 skill-forge 用户，介绍如何从自然语言需求自动生成可交付的技能包。

## 快速开始

1. 打开 skill-forge 网页界面（默认 `http://127.0.0.1:8710`）
2. 选择或创建一个项目
3. 在"生成新技能"输入框中输入需求描述，例如：
   > 把会议纪要整理成结构化行动项列表，每项包含负责人、截止日期和状态
4. 点击提交，系统自动进入生成流程

## 生成流程

提交后系统自动依次执行以下阶段，无需人工搬运：

| 阶段 | 说明 | 用户是否需要操作 |
|------|------|-----------------|
| 需求提取 | 解析自然语言，生成结构化需求合同 | 如果有信息缺口，需回答必要问题 |
| 工程规划 | 将需求映射为文件结构和验收标准 | 否 |
| 代码生成 | 按规划逐文件生成技能代码 | 否 |
| 静态验证 | 检查文件完整性、路径规范、扩展名等 | 否 |
| 版本冻结 | 将候选冻结为不可变版本 | 否 |
| 交付 | 生成交付收据（五维度状态） | 否 |

### 必要缺口

当系统无法从需求描述中确定某些必要信息时，流程会暂停在 **等待输入** 状态，页面显示待回答问题。回答后点击提交，流程自动继续。

### 交付收据

交付后可查看五维度验证状态：

- **静态验证**：文件完整性、路径规范、扩展名等检查
- **执行验证**：运行时行为验证（需宿主环境支持）
- **覆盖验证**：需求到验收的覆盖证明
- **宿主验证**：目标平台原生触发验证
- **人工验证**：人工复核（需用户确认）

## 导出

交付完成后，点击"导出"按钮生成 ZIP 包，包含：

- 技能文件（SKILL.md、脚本等）
- `delivery/` 目录：收据、合同、验证报告、工程画像
- `README.md`：使用说明与依赖列表

ZIP 可直接导入目标平台（如 CatPaw）安装使用。

## 取消

在流程未完成前可随时点击"取消"按钮。取消后流程不再继续，已生成的中间产物保留在版本目录中。

## 刷新恢复

页面刷新或意外断开后，系统通过本地存储自动恢复到上次的生成流程，无需重新提交。

## 桥接客户端

除网页界面外，可通过 Python API 显式提交需求：

```python
from app.generation.skill_bridge import forge_client

snapshot = forge_client.submit(
    request={"request_text": "把会议纪要整理成行动项"},
    base_url="http://127.0.0.1:8710",
    token="your-session-token",
    project_id="your-project-id",
)
```

注意：`request_text` 为必填——缺失时抛 ValueError，防止已有 skill 或一次性任务误进生成流程。
